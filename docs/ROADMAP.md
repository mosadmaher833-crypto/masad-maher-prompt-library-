# خارطة طريق مكتبة مسعد ماهر

## تم
- قاعدة بيانات JSON للبرومبتات.
- واجهة بحث وتصنيفات ومفضلة.
- مولد صور وفيديو بخيارات قابلة للاختيار.
- دليل مصادر.
- نظام تحديث دوري.
- Inbox للمراجعة.
- موصل GitHub مع معالجة Rate Limit.

## المرحلة التالية
- صفحة تفاصيل مستقلة لكل Prompt.
- فلاتر متقدمة: المجال، الأداة، الأسلوب، اللغة، الجودة، المصدر.
- ترتيب: الأحدث، الأعلى جودة، الأكثر استخدامًا.
- نظام نسخ متعددة للبرومبت نفسه.
- تقييم وتحسين البرومبت قبل الاستخدام.
- تصدير Prompt بصيغ Markdown / JSON / TXT.
- تحسين تجربة الهاتف.
- نشر رسمي عبر GitHub Pages.

## المرحلة المتقدمة
- موصلات RSS/API للمصادر التي توفر واجهات معلنة.
- مراجعة آلية + مراجعة بشرية.
- سجل تغييرات لكل Prompt.
- إحصائيات الاستخدام والمفضلة محليًا.
- مكتبة قوالب قابلة لإعادة الاستخدام.
- بحث دلالي مستقبلًا عند توفر خدمة مناسبة.
