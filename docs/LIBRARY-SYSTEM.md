# نظام مكتبة مسعد ماهر للـPrompts

## 1. إضافة مصدر جديد
- يسجل الاسم، الرابط، النوع، المجال، اللغة، وهل المصدر رسمي/مجتمعي.
- يمنع تكرار المصدر.

## 2. إضافة Prompt جديد
كل Prompt يحتوي على:
- العنوان
- المجال
- الأداة/النموذج
- الهدف
- Prompt بالعربية
- Prompt بالإنجليزية عند الحاجة
- المتغيرات `[PLACEHOLDER]`
- المصدر والرابط
- تاريخ الإضافة
- الوسوم
- التقييم والملاحظات

## 3. هندسة Prompt للصور
الموضوع → الوضعية → البيئة → التكوين → الكاميرا → الإضاءة → الأسلوب → التفاصيل → القيود → الناتج

## 4. هندسة Prompt للفيديو
الموضوع → الحركة → البيئة → حركة الكاميرا → الحركة البيئية → التوقيت → الإضاءة → الأسلوب → الصوت → القيود

## 5. المجالات
الصور، الفيديو، المحتوى، الإعلانات، التعليم، الأعمال، البرمجة، المقاولات، البيانات، العروض التقديمية، البحث، التسويق.

## 6. دورة التحديث اليومية
1. فحص المصادر المسجلة.
2. فحص المصادر الرسمية ومجتمعات البرومبتات والسوشيال ميديا العامة المتاحة.
3. استخراج الجديد.
4. إزالة المكرر.
5. تصنيف المحتوى.
6. تسجيل المصدر والتاريخ.
7. مراجعة الجودة.
8. إدراج المحتوى المقبول في المكتبة.
9. تسجيل المصادر الجديدة المقترحة.

> ملاحظة: التحديث الآلي يعتمد على المصادر التي يمكن الوصول إليها بشكل قانوني وتقني؛ المواقع المغلقة أو التي تمنع الوصول الآلي لا يتم تجاوز حمايتها.
