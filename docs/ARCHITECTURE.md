# معمارية مكتبة مسعد ماهر للـPrompts

## المكونات
- `index.html`: الواجهة الرئيسية والبحث والتصنيفات والمفضلة.
- `prompt-generator.html`: مولد البرومبتات بنظامي الصور والفيديو.
- `sources.html`: دليل المصادر.
- `data/prompts.json`: قاعدة البرومبتات المنشورة.
- `data/sources.json`: المصادر المعتمدة.
- `data/inbox/`: برومبتات مرشحة للمراجعة قبل النشر.
- `scripts/`: التحديث والتحقق والموصلات.
- `.github/workflows/`: التشغيل الدوري الآلي.

## دورة حياة البرومبت
1. اكتشاف من مصدر معلن.
2. استخراج النص والبيانات المصدرية.
3. تنظيف وتوحيد النص.
4. إزالة التكرار بالـhash.
5. تقييم الجودة من 10.
6. وضعه في `inbox` بحالة `pending_review`.
7. مراجعة بشرية.
8. نشره في `data/prompts.json`.

## مبادئ الجودة
- لا ننشر نصًا فارغًا أو مكررًا.
- نحافظ على رابط المصدر.
- لا نعتمد على كشط عشوائي للمواقع.
- لا يتم النشر التلقائي للمرشحات منخفضة الثقة.
- نحافظ على البرومبتات الموجودة عند التحديث.

## الصيغ الأساسية
### الصور
الموضوع → الوضعية → البيئة → التكوين → الكاميرا → الإضاءة → الأسلوب → التفاصيل → القيود → الناتج

### الفيديو
الموضوع → الحركة → البيئة → حركة الكاميرا → الحركة البيئية → التوقيت → الإضاءة → الأسلوب → الصوت → القيود

### النصوص والمهام العامة
الدور → السياق → البيانات → الهدف → التعليمات → القيود → الناتج → معايير الجودة
