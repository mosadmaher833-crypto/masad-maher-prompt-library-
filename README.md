# مكتبة البرومبتات

مستودع منظّم لحفظ البرومبتات وإعادة استخدامها وتطويرها. تُقسَّم البرومبتات حسب المجال، ويحتوي كل ملف على الهدف من البرومبت، والنص الجاهز للاستخدام، ومثالاً للمدخلات المتوقعة.

## محتويات المكتبة

| المسار | المحتوى |
| --- | --- |
| [`prompts/writing/`](prompts/writing/) | برومبتات الكتابة والتحرير والتلخيص. |
| [`prompts/coding/`](prompts/coding/) | برومبتات البرمجة ومراجعة الشيفرة وحل المشكلات التقنية. |
| [`prompts/business/`](prompts/business/) | برومبتات التخطيط والأعمال والتسويق. |
| [`prompts/learning/`](prompts/learning/) | برومبتات التعلّم والبحث وشرح المفاهيم. |
| [`templates/`](templates/) | قوالب موحّدة لإنشاء برومبتات جديدة. |
| [`guides/`](guides/) | إرشادات تنظيم وكتابة البرومبتات. |

## البدء

1. اختر التصنيف الأنسب داخل مجلد `prompts`.
2. انسخ ملف القالب [`templates/prompt-template.md`](templates/prompt-template.md).
3. سمِّ الملف باسم وصفي قصير، مثل `summarize-article.md`.
4. املأ الأقسام المطلوبة، ثم جرّب البرومبت ودوّن أي ملاحظات أو قيود.

## صيغة البرومبت

استخدم الأقواس المربعة للبيانات التي سيستبدلها المستخدم، مثل `[الموضوع]` و`[الجمهور المستهدف]`. اجعل التعليمات محددة، واذكر شكل النتيجة المطلوبة بوضوح.

راجع [دليل المساهمة](CONTRIBUTING.md) قبل إضافة برومبت جديد.
