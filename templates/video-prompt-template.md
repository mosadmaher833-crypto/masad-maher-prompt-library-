# قالب Prompt احترافي للفيديو

> الموضوع → الحركة → البيئة → حركة الكاميرا → الحركة البيئية → التوقيت → الإضاءة → الأسلوب → الصوت → القيود

## الموضوع
[الشخص / المنتج / العنصر الرئيسي]

## الحركة
[الحركة الأساسية للشخص أو العنصر]

## البيئة
[المكان، الخلفية، الزمن، الظروف]

## حركة الكاميرا
[Pan / Tilt / Dolly / Tracking / Orbit / Zoom / Static]

## الحركة البيئية
[الرياح، الشعر، الملابس، الدخان، المطر، الجمهور، السيارات، إلخ]

## التوقيت
[المدة، سرعة الحركة، البداية، النهاية، الانتقال]

## الإضاءة
[نوع الضوء، اتجاهه، التغير أثناء اللقطة]

## الأسلوب
[سينمائي، واقعي، إعلاني، وثائقي، خيالي، إلخ]

## الصوت
[الحوار، المؤثرات، البيئة، الموسيقى، الصمت]

## القيود
[ثبات الهوية، منع التشوه، منع العناصر غير المطلوبة، إلخ]

## Prompt النهائي
```text
[الموضوع] يقوم بـ[الحركة] في [البيئة]، بينما تتحرك الكاميرا بـ[حركة الكاميرا]، مع [الحركة البيئية]، خلال [التوقيت]، بإضاءة [الإضاءة]، بأسلوب [الأسلوب]، مع صوت [الصوت]، والالتزام بـ[القيود].
```
