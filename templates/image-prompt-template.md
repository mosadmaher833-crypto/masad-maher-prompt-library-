# قالب Prompt احترافي للصور

> الموضوع → الوضعية → البيئة → التكوين → الكاميرا → الإضاءة → الأسلوب → التفاصيل → القيود → الناتج

## الموضوع
[الشخص / المنتج / العنصر الرئيسي]

## الوضعية
[الوضعية، التعبير، اتجاه الجسم]

## البيئة
[المكان، الخلفية، الزمن، الطقس]

## التكوين
[نوع التكوين، المقدمة/الوسط/الخلفية، التوازن، المساحة السلبية]

## الكاميرا
[نوع اللقطة، زاوية التصوير، العدسة، عمق المجال]

## الإضاءة
[مصدر الضوء، الاتجاه، الشدة، الظلال، وقت اليوم]

## الأسلوب
[واقعي، سينمائي، إعلاني، فني، ثلاثي الأبعاد، إلخ]

## التفاصيل
[الخامات، الألوان، الملابس، الملمس، المؤثرات]

## القيود
[ما يجب الحفاظ عليه أو تجنبه، مثل عدم تغيير ملامح الوجه]

## الناتج
[نسبة الأبعاد، الدقة، التكوين النهائي، عدد الصور]

## Prompt النهائي
```text
[الموضوع]، [الوضعية]، في [البيئة]، بتكوين [التكوين]، مصور بـ[الكاميرا]، بإضاءة [الإضاءة]، بأسلوب [الأسلوب]، مع [التفاصيل]، مع الالتزام بـ[القيود]، الناتج [الناتج].
```
