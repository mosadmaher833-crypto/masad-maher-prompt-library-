# مصادر مكتبة مسعد ماهر للـPrompts

هذا المجلد هو سجل المصادر المعتمدة التي ستُستخدم لاكتشاف البرومبتات، الأدلة، النماذج، وأفضل ممارسات هندسة الأوامر.

## التصنيفات

- `prompt-library` — مكتبات البرومبتات العامة.
- `official-prompt-engineering` — المصادر الرسمية لهندسة الأوامر.
- `prompt-engineering` — الأدلة والمراجع المتخصصة.
- `image-prompts` — مصادر برومبتات الصور.
- `image-specialized` — أدوات ونماذج الصور.
- `video-specialized` — أدوات ونماذج الفيديو.

## ملف البيانات

كل المصادر موجودة أيضًا بصيغة قابلة للقراءة البرمجية في:

`/sources/sources.json`

ويمكن لاحقًا إضافة حقول مثل: حالة المصدر، آخر فحص، آخر برومبت تمت إضافته، طريقة الاستخراج، الوسوم، ومستوى الثقة.
